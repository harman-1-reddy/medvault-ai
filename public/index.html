MedVault AI — Safety, Grounding & Ethics Architecture

1. Reference-Range Grounding Policy The system strictly determines High/Low/Normal flags from the source document’s printed reference ranges. If a lab omitted an interval, MedVault flags it as Range Not Provided and never invents standard thresholds.
2. Strict Provenance Tagging Every data point is tagged as USER_INTAKE, EXTRACTED_DOCUMENT, or AI_INFERRED. Clicking on any table cell displays the exact line and file origin.
3. Non-Diagnostic Boundary MedVault explicitly abstains from issuing definitive medical diagnoses or recommending prescription changes. Summaries provide patient empowerment and actionable questions to ask their licensed clinician.
